# 表头白话说明

这些数字量的是「人在 VibeTrace 网页里干什么」，不是 agent 算了多久。

## 时长相关

| 列名 | 人话 |
|------|------|
| 任务总时长（分钟） | 从这个任务的录制开始，到录制结束，过了多少分钟。人走开、切窗口、发呆都算在里面，所以会偏长。 |
| 鼠标在界面上停留（分钟） | 鼠标真正停在各个面板上的时间加总。人走开就不计。通常比「任务总时长」短很多。 |
| 停留占任务时长 | 上面两个相除。越低说明中间越常离开页面或没把鼠标放在面板上。 |
| 第一次碰轨迹相关面板 | 任务开始后过了几分钟，才第一次碰右侧轨迹 / todo / skill 等（不是纯 chat）。 |
| 最后一次离开轨迹相关面板 | 任务开始后过了几分钟，最后一次从这些面板上挪开鼠标。 |
| 从第一次到最后一次中间隔了多久 | 第一次碰 → 最后一次离开，中间这段「会去看轨迹功能」的时间窗。中间可以夹杂看 chat、发呆。 |
| 该间隔占任务总时长 | 时间窗 / 任务总时长。 |

注意：**「鼠标停留总分钟」** 和 **「第一次到最后一次的间隔」** 本来就不会相等——前者只加悬停毫秒；后者是墙钟时间窗，中间空隙也算进去。

## 占比相关

| 列名 | 人话 |
|------|------|
| chat / 轨迹 / todo … 占比 | 鼠标停在各面板的时间，占「所有面板停留时间」的百分之几。加起来约 100%。 |
| VibeTrace 相关合计 | 轨迹+todo+tooltip+skill+任务条，不含纯 chat / session。 |
| 前/中/后期 VibeTrace 占比 | 把任务总时长切成三段；在每一段里，停在 VibeTrace 相关面板的比例。 |

## 路径

按真实日志里「第一次点/滚/发」的区域顺序，例如 chat → trajectory → todo。
